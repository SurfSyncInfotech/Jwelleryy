# Image paths

Real jewellery photographs belong in this folder. Product records already point at unique files, for example:

`/images/products/rings/ring-001-primary.jpg`

Until a file exists, the site draws a distinct placeholder for that piece. Dropping a licensed image at the same path replaces the placeholder. Do not point two products at one file.
